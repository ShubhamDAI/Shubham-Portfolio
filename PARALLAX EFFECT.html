About the Project

This project demonstrates the Parallax Scrolling Effect using HTML and CSS. It consists of six full-screen sections representing different seasons, including Summer, Spring, Monsoon, Autumn and Winter. Each section uses different background images, and the fixed background attachment creates a parallax effect while scrolling the webpage.

Tools Used

HTML CSS CSS Background Properties CSS Linear Gradient CSS Backdrop Filter

Features

  • Six full-screen sections covering different seasons.
  • Different background images for each season.
  • Fixed background images using background-attachment: fixed.
  • Gradient background in the first section.
  • Center-aligned text with large font size.
  • Background images adjusted using background-position and background-size.
  • Blur effect behind text using backdrop-filter.

What I Learned

  • How to create webpage sections using HTML div elements.
  • How to apply background images using CSS.
  • How the background-attachment: fixed property creates a parallax effect.
  • How to use linear-gradient() for background styling.
  • How to control background images using background-position, background-size and background-repeat.
  • How to style text using CSS font properties.
  • How to apply blur effects using backdrop-filter.
