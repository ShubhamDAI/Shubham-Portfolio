About the Project

This project demonstrates a Student Registration Form created using HTML and CSS. It provides a simple registration interface where users can enter their full name, email address and password. The form includes Submit and Reset buttons to handle user input. It also features a navigation bar, a background image and a side image to make the registration page visually attractive.

Tools Used

HTML CSS HTML Forms Input Elements CSS Flexbox

Features

  • Navigation bar with Home, About Us, Contact and Our Services links.
  • Registration form with Full Name, Email and Password fields.
  • Email validation using the HTML pattern attribute.
  • Required fields to ensure users enter the necessary information.
  • Submit button to submit the registration form.
  • Reset button to clear the entered information.
  • Background image with a cover property.
  • Side image displayed alongside the registration form.
  • Transparent form container with rounded corners and box shadow.
  • Hover effects on navigation links and buttons.

What I Learned

  • How to create the basic structure of an HTML document.
  • How to design registration forms using HTML input elements.
  • How to use different input types such as text, email and password.
  • How to apply required and pattern attributes for form validation.
  • How to create navigation bars using HTML and CSS.
  • How to use CSS Flexbox for arranging elements side by side.
  • How to add background images and adjust their positions.
  • How to style buttons, borders, spacing and hover effects using CSS.
  • How to create transparent backgrounds using RGBA colors.
