About This Project

The School Management Dashboard is an Excel-based data analytics project designed to organize, analyze, and visualize school-related information. It presents important information about schools, teachers, students, and parents through an interactive dashboard. It helps users understand school data quickly and make better decisions.

Tools Used

Microsoft Excel Pivot Tables and Pivot Charts Slicers for interactive filtering Excel Formulas and Functions VBA (Visual Basic for Applications) for automation

Key Features

  • Interactive dashboard for school-related data.
  • KPI cards displaying Schools, Teachers, Students, and Parents.
  • Pivot Charts for data visualization.
  • Day and Month slicers for filtering data.
  • Attendance and calendar-related information.
  • Timetable automation using VBA macros.
  • Exporting the timetable as a PDF file.

What I Learned

  • How to clean, organize, and analyze data in Excel.
  • How to create interactive dashboards using Pivot Tables and Charts.
  • How to use slicers to filter and explore data.
  • How to display important information using KPI cards.
  • How to automate repetitive tasks using VBA macros.
  • How to export Excel worksheets into PDF format using VBA.
  • How to present data in a clear and meaningful way.
