UPDATE

Private Sub CommandButton3_Click()

Dim lr As Long
lr = Range("A1048576").End(xlUp).Row

Dim y As Long

For y = 2 To lr
    If TextBox5.Text = Cells(y, 1) Then
        Cells(y, 1) = TextBox2.Value
        Cells(y, 2) = TextBox3.Value
        Cells(y, 3) = ComboBox1.Value
        Cells(y, 4) = ComboBox2.Value
        Cells(y, 5) = TextBox4.Value
    End If
Next y

Call refresh_data

End Sub

FETCHING DATA INTO LISTBOX

Sub refresh_data()

Dim lr As Long
lr = Range("A1048576").End(xlUp).Row

If lr = 1 Then lr = 2

ListBox2.ColumnCount = 5
ListBox2.ColumnHeads = True
ListBox2.RowSource = "A2:E" & lr

End Sub

About the Project

This is an Employee Management System developed using Microsoft Excel and VBA. It allows users to manage employee records through a UserForm. Employee ID, name, designation, department and salary are stored in an Excel worksheet. The system provides options to add, search, update and delete employee records easily.

Tools Used

Microsoft Excel VBA (Visual Basic for Applications) Excel UserForms TextBox ComboBox ListBox Command Buttons

Features

  • Add new employee records to an Excel worksheet.
  • Store employee ID, name, designation, department and salary.
  • Search employee records using Employee ID.
  • Update existing employee information.
  • Delete employee records from the worksheet.
  • Display employee records in a ListBox.
  • Select designation and department using dropdown lists.
  • Load employee details into the form by double-clicking a record.
  • Reset or close the UserForm.
  • Refresh the ListBox after adding, updating or deleting records.
